# Consent for voice cloning and dubbing

Rule (CLAUDE.md non-negotiable 10): never clone or dub a person's voice without their explicit, written consent. AI-dubbed audio is always labeled "AI-dubbed" and is never presented as the person's own words. Noor's voice is never synthesized.

Status values: `pending` (asked or planned, no written yes on file) and `confirmed` (written yes on file; the captain sets this). The pipeline refuses to use any dubbed audio whose row here is not `confirmed`.
